# Neural Network MLP Classifier

This project focuses on developing an optimized Multi-Layer Perceptron (MLP) classifier using a two-stage hyper-parameter tuning process. The goal is to achieve high classification accuracy (≥ 95%) on a dataset containing inputs from three distinct classes, visualized in a 2D plot (see Figure 1 in the project description).

## Project Overview

The dataset consists of samples from three classes, which are separable in low-dimensional space, as shown in the 2D scatter plot. Given the simplicity of the classification task, the project emphasizes:

- **Efficient Neural Network Design**: A small number of parameters to ensure fast convergence.
- **Two-Stage Hyper-Parameter Tuning**: Systematically finding an optimal configuration for the MLP classifier.
- **Strict Training Limits**: Prioritizing computational efficiency and model performance.

The MLP classifier is implemented to achieve robust performance with minimal complexity, making it suitable for resource-constrained environments.

## Dataset

- **Description**: The dataset contains input samples belonging to three classes.
- **Visualization**: A 2D scatter plot (Figure 1) illustrates the separability of the classes.
- **Task**: Multi-class classification in low-dimensional space.
